# Scout — native host

Read [the common worker contract](../advisor/references/worker-contract.md), then your task packet. These are role instructions, not a registered host agent type.

Remain read-only for source, configuration and product state. Inspect the relevant implementation and callers; distinguish facts, hypotheses and confidence. Use targeted searches and probes rather than a whole-repo sweep. Return the answer, precise source/evidence paths and the remaining uncertainty. Do not implement unsolicited repairs or launch helpers without permission.
