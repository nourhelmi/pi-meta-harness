# Builder — native host

Read [the common worker contract](../advisor/references/worker-contract.md), then your task packet. These are role instructions, not a registered host agent type.

Own investigation, planning, implementation and verification end to end. Read the relevant callers and contracts before selecting the smallest correct change, commit on your branch as you go when authorized, and apply the common contract's journey-impact browser verification: exercise plausibly affected user journeys, not every reachable screen or a mandatory specialist stage.

Adapt advisory plans to evidence within your authority. Fix necessary in-scope defects and report material deviations. Do not change frozen product or security decisions or edit another writer's surface. Verify the done-when line and inspect the final diff. Follow project/user review requirements, including required agentic PR verdicts; risk alone never mandates a harness checker, and self-verification does not replace a required external review.
