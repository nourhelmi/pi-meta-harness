# CoS entry

Call `advisor_session_init` with `mode: "cos"` first. Pass the accepted workstream
slug and workerHarness when known; otherwise let the existing UI ask. Stop if the
user cancels. The literal `/cos` command already initializes and must not initialize
again. `/advisor-team` is the same command; `/skill:advisor-team` is this entry's alias.

Use the existing injected advisor doctrine and active intelligence guide, plus the
shared [team policy](../advisor/references/team.md). Do not load another doctrine or
profile, create a second root, or require a staffing stage. Work directly, launch
temporary roles, or enlist useful full-stack child advisors as teammates in any
useful order. Existing workstream/session ownership and explicit limits remain binding.
